# PRE-IMPLEMENTATION AUDIT

## Initial State (HERO-01)
- **Hierarchy:** Eyebrow -> Vitrine360 (Redundant) -> Headline (4 lines).
- **Scale:** Headline was too large (68px) and forced into narrow columns, pushing content down.
- **Composition:** Hero content occupied too much vertical space; CTAs were forced below the fold on some viewports. Player demo felt small and visually disconnected, like a "card" rather than a real product window.
- **Visual Weight:** Playlist had heavy styling (borders, shadows, distinct separators) which competed with the main media area.

## Goals (HERO-02)
- Recompose the hero into 4 strict levels: Eyebrow, Headline (max 3 lines), Copy+CTA, Product Showcase.
- Make the Player feel like a "product window" rather than a UI component within a section.
- Expand the Player width and increase its visual dominance.
- Soften and minimize the playlist, letting the media area command attention.
- Clean up the Navbar and Hero background to remove visual noise.
