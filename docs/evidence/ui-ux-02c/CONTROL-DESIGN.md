# UI/UX-02C — Control Design

## Vocabulary (visual)

PLAY · PAUSE · STOP · PREVIOUS · NEXT · RESTART · SEEK · VOLUME · MUTE · FULLSCREEN

Future (not shown as enabled): SPEED · PiP · SUBTITLES · QUALITY

## Patterns

- Icon-only circular / pill controls for media ops
- Primary Play = filled purple circle
- Secondary = ghost on glass
- Disabled opacity ~40%
- `aria-label` includes “Coming soon”

No giant rectangular playback toolbars.
